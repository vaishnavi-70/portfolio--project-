# Personal Portfolio Website

A full-stack personal portfolio web application built to showcase projects, skills, and professional background with a connected backend database for handling user interactions or contact messages.

---

## Features

* **Interactive Frontend**: Clean and responsive user interface built with HTML5, CSS3, and JavaScript.
* **Backend Integration**: RESTful API built using Node.js and Express to handle data processing.
* **Database Management**: MongoDB integration for securely storing records or contact form submissions.
* **Environment Configuration**: Uses `.env` files to protect sensitive credentials and database keys.

---

## Tech Stack

* **Frontend**: HTML5, CSS3, JavaScript (ES6+)
* **Backend**: Node.js, Express.js
* **Database**: MongoDB, Mongoose

---

## Project Structure

* `server.js` - Entry point for the Express backend server.
* `public/` - Contains static frontend assets (HTML, CSS, client-side JS).
* `.env` - Environment variables configuration.
* `package.json` - Project metadata and dependencies.
